# 쌀집 계산기 기능 리스트

## 📋 개요

데스크톱 계산기 애플리케이션입니다. 정확한 소수점 계산을 지원하며, 직관적인 인터페이스로 쉽게 사용할 수 있습니다.

---

## 🔢 기본 입력 기능

| 버튼 | 기능명      | 사용 방법                        | 특징                                                                                                                                                                                                                      |
| ---- | ----------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0-9  | 숫자 입력   | 숫자 버튼을 클릭하여 숫자 입력   | • 화면에 "0"이 표시된 상태에서 숫자를 입력하면 자동으로 교체<br>• "-0" 상태에서 숫자를 입력하면 "-숫자" 형태로 변환<br>• 연산을 시작한 후에는 두 번째 숫자를 입력 가능<br>• 계산 결과 후 숫자를 입력하면 새로운 계산 시작 |
| .    | 소수점 입력 | 소수점 버튼을 클릭하여 소수 입력 | • 정수에만 소수점을 추가 가능<br>• 이미 소수점이 있는 숫자에는 추가 불가 (중복 방지)                                                                                                                                      |

---

## 🧮 사칙연산 기능

| 버튼 | 기능명 | 사용 방법                                                         | 특징                                                                                                                             |
| ---- | ------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| +    | 덧셈   | 첫 번째 숫자 입력 → + 버튼 클릭 → 두 번째 숫자 입력 → = 버튼 클릭 | • 연산자를 연속으로 누르면 자동으로 계산 수행<br>• 예: `1 + 2 + 3` → `1 + 2 = 3`, `3 + 3 = 6`                                    |
| -    | 뺄셈   | 덧셈과 동일한 방식으로 사용                                       | 덧셈과 동일한 동작 방식                                                                                                          |
| \*   | 곱셈   | 덧셈과 동일한 방식으로 사용                                       | 덧셈과 동일한 동작 방식                                                                                                          |
| /    | 나눗셈 | 덧셈과 동일한 방식으로 사용                                       | ⚠️ 0으로 나누기 시 "ERR" 표시, AC 버튼으로 초기화 필요                                                                           |
| =    | 등호   | 숫자와 연산자를 입력한 후 = 버튼 클릭                             | • 계산 결과가 화면에 표시<br>• 결과 후 연산자를 누르면 결과값과 연산자로 이어서 계산<br>• 결과 후 숫자를 누르면 새로운 계산 시작 |

---

## 🔧 편의 기능

| 버튼 | 기능명             | 사용 방법                                           | 특징                                                                                                                                           |
| ---- | ------------------ | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| +/-  | 부호 변경          | +/- 버튼을 클릭하여 현재 입력 중인 숫자의 부호 변경 | • 양수를 음수로, 음수를 양수로 변환<br>• 계산 중에도 언제든지 부호 변경 가능                                                                   |
| CE   | 현재 입력값 초기화 | CE 버튼을 클릭하여 현재 입력 중인 숫자만 초기화     | • 계산 중이 아닐 때: 첫 번째 숫자만 "0"으로 초기화<br>• 계산 중일 때: 두 번째 숫자만 "0"으로 초기화<br>• 이전 계산 결과나 연산자는 그대로 유지 |
| AC   | 전체 초기화        | AC 버튼을 클릭하여 모든 상태 초기화                 | • 모든 입력값과 연산이 초기화<br>• 에러 상태도 해제<br>• 화면에 "0"이 표시되며 처음부터 다시 계산 가능                                         |

## ⚠️ 에러 처리

| 에러 유형      | 발생 상황                        | 화면 표시         | 해결 방법                            | 주의사항                                  |
| -------------- | -------------------------------- | ----------------- | ------------------------------------ | ----------------------------------------- |
| 0으로 나누기   | 어떤 숫자를 0으로 나누려고 할 때 | "ERR" 메시지 표시 | AC 버튼을 눌러 초기화한 후 다시 계산 | 에러 상태에서는 숫자 입력이나 연산 불가능 |
| 기타 계산 에러 | 계산 중 예상치 못한 오류 발생    | "ERR" 메시지 표시 | AC 버튼을 눌러 초기화한 후 다시 계산 | 에러 상태에서는 숫자 입력이나 연산 불가능 |

## 💡 사용 팁

| 팁 유형              | 설명                                                                 | 예시                                            |
| -------------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| 연속 계산하기        | 계산 결과 후 연산자 버튼을 누르면 결과값과 연산자로 이어서 계산 가능 | `10 + 5 = 15` → `* 2 = 30` → `- 10 = 20`        |
| 새로운 계산 시작하기 | 계산 결과 후 숫자 버튼을 누르면 새로운 계산 시작                     | `10 + 5 = 15` → `3` 입력 시 → `3`부터 새로 시작 |
| 실수 입력하기        | 정수를 입력한 후 소수점 버튼을 누르고 숫자를 입력하면 소수 입력 가능 | `123` → `.` → `45` → `123.45`                   |
| 자동 계산            | 연산자 버튼을 연속으로 누르면 자동으로 계산 수행                     | `1 + 2 + 3` → 중간 결과 자동 계산 → 최종 결과   |

---

## ✨ 계산 정확도

| 항목        | 설명                                          | 예시                                     |
| ----------- | --------------------------------------------- | ---------------------------------------- |
| 소수점 계산 | 정확한 소수점 계산 지원, 부동소수점 오차 없음 | 일반 계산기보다 정확한 결과 제공         |
| 결과 표시   | 불필요한 0은 자동으로 제거                    | `1.0` → `1`, `1.50` → `1.5`, `0.0` → `0` |

## 📱 UI 구성

| 구성 요소   | 설명                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 숫자 버튼   | 0-9 (10개)                                                           |
| 연산자 버튼 | +, -, \*, /, = (5개)                                                 |
| 기능 버튼   | . (소수점), +/- (부호 변경), CE (현재 입력 초기화), AC (전체 초기화) |
| 화면 표시   | 읽기 전용 텍스트 필드, 초기값 "0", 모든 입력/연산 시 실시간 업데이트 |

## 🔒 사용 시 주의사항

| 주의사항     | 설명                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| 에러 발생 시 | 에러("ERR")가 표시되면 AC 버튼을 눌러 초기화 필요, 에러 상태에서는 숫자 입력이나 연산 불가능 |
| 소수점 입력  | 정수에만 소수점을 추가 가능, 이미 소수점이 있는 숫자에는 소수점 추가 불가                    |
